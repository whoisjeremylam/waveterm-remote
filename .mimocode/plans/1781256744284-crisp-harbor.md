# Plan: Fix heldData Not Drained After Terminal Load

## Problem

When WaveTerm restarts with durable sessions, the `mainFileSubject` subscription (line 443) happens BEFORE `loadInitialTerminalData()` completes (line 468). Live `blockfile` events arriving during the async load are pushed to `heldData` (line 519), but `heldData` is **never drained** after `loaded = true` (line 470). This causes data loss for events in the narrow window between HTTP fetch completion and `loaded = true`.

## Fix

**File:** `frontend/app/view/term/termwrap.ts`

In `initTerminal()`, drain `heldData` after setting `loaded = true`:

```typescript
try {
    await this.loadInitialTerminalData();
} finally {
    this.loaded = true;
    // Drain any events that arrived during async loading
    if (this.heldData.length > 0) {
        for (const data of this.heldData) {
            this.doTerminalWrite(data, null);
        }
        this.heldData = [];
    }
}
```
